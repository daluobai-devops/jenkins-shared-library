# Isolate deliverable unit workspace lifecycles

仓库分发 Job 串行执行可交付单元，每个单元开始前先将任务工作目录完整清空，再独立检出源码，结束时再次清理；后续单元可以顺序复用同一物理目录，无需按可交付单元标识分配不同目录。开始前清理失败时当前单元立即失败，不拉取代码或执行任何交付阶段，调度器继续尝试后续单元。显式声明的构建缓存必须位于工作空间之外，可以跨可交付单元共享，但不能包含源码、构建产物或任务临时文件；其他内容不能跨单元继承。不同单元的源码目录可以部分或完全重叠，构建命令和相对文件路径仍以各自单元源码目录为边界。该选择依赖严格的串行执行和任务级完整清理，以减少目录管理复杂度，同时维持按可交付单元隔离失败的边界。
