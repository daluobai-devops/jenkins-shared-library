# Preflight delivery before running any stage

环境交付执行必须在构建、产物存储或部署开始前，对有效交付配置完成统一预检，包括阶段组合、必填字段、策略互斥、最多一个产物存储目标、产物依赖与可达性、应用标识、源码引用、单元源码目录和目标节点。当前合法阶段组合完整限定为：仅构建、构建加存储、支持直接产物交接时的构建加部署，以及构建加存储加部署；其他组合全部预检失败，策略实现不得绕过该矩阵。历史产物复制、历史产物部署和仅重启仍不属于当前正式能力。预检将分支、Tag 或 SHA 形式的源码引用解析并固定为本轮 Commit SHA，校验该版本下的单元源码目录；实际构建必须检出这一固定版本，不能在执行时重新跟随已移动的分支。任一校验失败时立即失败，不执行任何交付阶段。`deployJavaWeb`、`deployWeb` 的真实执行与仓库分发 Job 的 `dryRun` 必须复用同一套内部预检能力；直接入口采用“预检通过后执行”，分发 `dryRun` 只预检而不执行交付阶段或发送通知。该选择用前置校验复杂度换取无副作用失败，并防止多条入口路径的校验规则漂移。
