# Use an explicit marker to clear inherited defaults

统一交付配置仅允许凭据别名字段使用精确字符串 `-` 清除从较低优先级配置层继承的值；凭据别名字段缺失或空字符串继续继承，`null` 作为无效配置被拒绝，其他配置字段不赋予 `-` 特殊语义。显式标记避免空字符串因模板、参数或 Jenkins 表单默认值而意外关闭凭据，同时仍允许 HTTPS 公共仓库等场景主动取消共享库默认值。

每个配置层在合并前独立校验凭据别名，因此低优先级层中的 `null` 即使会被高优先级合法值覆盖也必须失败。合并和清除标记归一化集中在配置解析入口完成，后续源码、构建和部署实现只消费归一化后的值。
