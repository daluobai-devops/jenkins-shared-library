# Recursively discover deliverable units

仓库分发 Job 配置一个精确的交付 Jenkinsfile 文件名，并在源码仓库中递归搜索全部同名文件；不支持通配符、正则表达式或同时配置多个名称。每一份匹配配置代表一个可独立交付的可交付单元，一个源码仓库可以包含多个可交付单元。配置文件所在的模块目录默认作为该单元的源码目录，而不是固定使用仓库根目录；需要使用父级或其他源码范围时，由该单元显式指定。该决策以支持多模块和 monorepo 为优先，替代 ADR-0009 的“一仓库一应用、一环境一配置”限制。每个单元必须显式提供在目标环境内唯一的应用标识，缺失时预检失败。
