# Follow the latest configuration during dispatch

仓库分发期间不为单个仓库冻结配置快照，每次目录或配置读取都跟随配置发现引用当时的最新状态，并为实际读取的每份配置记录对应 Commit SHA。每份配置在本轮只读取一次；通过完整预检后固定用于该单元本轮执行，不在构建前再次读取，以保持全局应用标识检查和预检结论有效。每个仓库在一轮分发中只执行一次递归目录扫描；扫描完成后新增的配置留到下一轮处理，不为持续追逐变化而重复扫描。扫描后、读取前已确认被删除的配置记为已撤回单元，不执行且不导致分发失败；无法确认删除的读取异常仍按失败处理。该选择优先让交付尽可能使用读取时的最新配置并保证单轮任务能够结束，接受同一次分发中目录结果和配置内容、以及不同可交付单元之间可能来自不同提交。
