# 02 — 通过替代入口完成 Java 应用仅构建交付

**What to build:** 提供第一条完整应用交付 tracer bullet：调用者使用当前统一配置进入替代入口，经过有效交付配置解析和交付预检后完成 Java 应用仅构建，并得到明确的交付结果。

**Blocked by:** 01 — 锁定既有入口兼容基线.

**Status:** ready-for-agent

- [ ] 替代入口只接受当前统一配置结构，并拒绝仅属于旧入口的配置结构。
- [ ] 有效交付配置按既定四层优先级生成，后续 implementation 只消费统一结构。
- [ ] 仅构建是合法交付阶段组合，预检通过后才执行构建。
- [ ] 空交付配置、无构建的无效组合和显式不支持的操作模式在预检中失败。
- [ ] 预检失败前不执行构建、产物存储、部署或交付通知。
- [ ] 构建成功和失败都产生调用者可观察的结果。
- [ ] 入口场景测试跨越应用交付入口契约，不把内部解析或预检方法设为 test surface。
- [ ] 既有入口及其兼容基线保持通过。
