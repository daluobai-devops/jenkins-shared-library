# 05 — 通过共享交付 seam 完成 Web 应用交付

**What to build:** 让当前统一配置可以通过替代入口完成 Web 应用构建、产物交接和原子部署，同时让既有 `deployWeb` 入口作为兼容 adapter 委托同一应用交付 implementation。

**Blocked by:** 04 — 存储不可变且命名隔离的构建产物.

**Status:** ready-for-agent

- [ ] 替代入口根据统一配置选择 Web 应用构建和部署策略。
- [ ] Web 应用在交付预检中验证应用标识、产物格式、部署节点、目标目录和产物可达性。
- [ ] 预检通过后按构建、可选产物存储、部署的合法顺序执行。
- [ ] Web 部署先准备并验证暂存内容，再原子切换线上目录。
- [ ] 切换失败时按既有规则恢复旧目录，并保留无法自动恢复时的诊断信息。
- [ ] 既有 `deployWeb` 合法旧配置在入口 adapter 转换后得到等价可观察结果。
- [ ] 替代入口不接受 `deployWeb` 专属旧结构。
- [ ] 新旧入口测试都跨越应用交付入口契约，兼容基线保持通过。
