# 03 — 固定源码版本并生成可追溯交付记录

**What to build:** 在仅构建交付中解析并固定源码引用，使实际构建使用预检确认的版本，并在交付结果中保留配置来源、源码引用和已解析版本等追溯事实。

**Blocked by:** 02 — 通过替代入口完成 Java 应用仅构建交付.

**Status:** ready-for-agent

- [ ] 分支、Tag 或 Commit SHA 在交付预检时解析为固定的已解析源码版本。
- [ ] 实际构建检出已解析源码版本，不在执行阶段重新跟随可移动引用。
- [ ] 不存在或无法授权读取的源码引用在交付副作用前失败。
- [ ] 可交付单元源码目录在已解析源码版本中验证，不存在时不回退或猜测其他目录。
- [ ] 交付结果记录配置来源、源码引用、已解析源码版本和交付结果。
- [ ] 外部源码事实通过生产 adapter 与内存 adapter 的真实 seam 提供。
- [ ] 测试证明引用在预检后移动也不会改变本轮构建版本。
- [ ] 既有入口兼容测试保持通过。
