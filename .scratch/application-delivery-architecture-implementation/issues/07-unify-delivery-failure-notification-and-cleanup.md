# 07 — 统一环境交付执行的失败、通知与清理语义

**What to build:** 让 Web 应用和 Java 应用共享同一个环境交付执行生命周期，使开始与结果通知、状态映射、主失败优先和强制工作区清理具有一致且可测试的行为。

**Blocked by:** 05 — 通过共享交付 seam 完成 Web 应用交付; 06 — 通过共享交付 seam 完成 Java 应用部署.

**Status:** ready-for-agent

- [ ] Web 和 Java 应用使用同一生命周期 implementation 管理状态、通知和清理。
- [ ] 交付预检通过前不发送交付通知。
- [ ] 成功、失败和终止状态产生规定的可观察通知行为。
- [ ] 主交付失败不会被后续通知失败或清理失败替换。
- [ ] 没有主交付失败时，强制清理失败使本次交付失败。
- [ ] 通知失败不会阻止工作区清理尝试。
- [ ] 有效交付配置和预检结果显式传入执行，不依赖可变全局配置。
- [ ] 生命周期测试从应用交付入口断言可观察结果，Web 和 Java 兼容基线保持通过。
