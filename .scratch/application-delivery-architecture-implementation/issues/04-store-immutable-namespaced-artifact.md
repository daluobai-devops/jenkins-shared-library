# 04 — 存储不可变且命名隔离的构建产物

**What to build:** 让当前执行生成的 Java 构建产物可以通过替代入口进入产物存储，并使用不可变、命名隔离的身份防止不同环境、应用或执行互相覆盖。

**Blocked by:** 03 — 固定源码版本并生成可追溯交付记录.

**Status:** ready-for-agent

- [ ] 构建加产物存储作为完整合法阶段组合通过交付预检。
- [ ] 启用产物存储但关闭构建时在预检中失败。
- [ ] 一次交付最多选择一个产物存储目标，多个目标在预检中失败。
- [ ] 存储产物身份至少包含目标环境、应用标识和 Jenkins 执行标识。
- [ ] 已存在的存储产物身份不能被覆盖。
- [ ] 存储结果记录内容校验值和可获取的产物引用。
- [ ] 相同源文件名的不同可交付单元得到不同存储身份。
- [ ] 构建失败时不尝试产物存储，存储失败时交付结果为失败。
