# 08 — 落实执行取代与工作区初始化规则

**What to build:** 让同一环境交付 Job 的新执行按既有决定取代活动执行，并在执行交付阶段前完成规定的等待、工作区初始化和残留处理。

**Blocked by:** 07 — 统一环境交付执行的失败、通知与清理语义.

**Status:** ready-for-agent

- [ ] 同一环境交付 Job 同时最多存在一个活动环境交付执行。
- [ ] 新执行取代未完成的旧执行，而不是与其并行执行交付阶段。
- [ ] 新执行等待旧执行退出并完成工作区清理尝试后再开始。
- [ ] 旧执行的清理失败使旧执行失败，但不阻断新执行继续初始化。
- [ ] 新执行开始时删除非声明残留，仅保留显式允许且位于工作区外的构建缓存。
- [ ] 工作区初始化失败时，新执行不进入构建、产物存储或部署。
- [ ] 取代通知包含新旧执行、应用、目标环境和旧执行是否进入部署阶段。
- [ ] 本地测试覆盖并发状态转换，测试 Jenkins 验收所需场景已可从公开入口触发。
