# 10 — 让分发预检运行复用完整交付预检

**What to build:** 让仓库分发 Job 的预检运行对 Web 和 Java 受限交付声明执行完整的有效交付配置解析与交付预检，产生与直接交付一致的结论，同时不执行任何交付副作用。

**Blocked by:** 05 — 通过共享交付 seam 完成 Web 应用交付; 06 — 通过共享交付 seam 完成 Java 应用部署; 09 — 建立可替换的 Codeup seam.

**Status:** ready-for-agent

- [ ] 仓库分发递归发现精确文件名匹配的所有受限交付声明。
- [ ] 每份声明只允许一个受支持入口调用和字面量配置。
- [ ] 仓库授权、远端命令值授权和 Shell 字符限制在交付预检前执行。
- [ ] 每个候选可交付单元生成有效交付配置并跨越同一交付预检 seam。
- [ ] Web 和 Java 的共享场景在直接交付与分发预检运行中产生相同判定和错误分类。
- [ ] 分发预检运行不执行构建、产物存储、部署或交付通知。
- [ ] 应用标识缺失或冲突、源码引用无效和阶段组合无效均在分发结果中明确记录。
- [ ] 配置读取失败、被拒绝和已撤回配置被区分，不把失败静默视为跳过。
