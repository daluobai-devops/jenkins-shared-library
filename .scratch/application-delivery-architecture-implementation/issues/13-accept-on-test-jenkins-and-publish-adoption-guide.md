# 13 — 在测试 Jenkins 验收并发布接入说明

**What to build:** 在测试 Jenkins Job `test` 中通过公开入口验收新旧应用交付和仓库分发行为，并发布替代入口接入、既有入口兼容和回退方式说明。

**Blocked by:** 12 — 收缩重复 implementation 并完成本地回归.

**Status:** ready-for-agent

- [ ] 测试 Jenkins 验收一个既有 Web 入口合法旧配置场景。
- [ ] 测试 Jenkins 验收一个既有 Java 入口合法旧配置场景。
- [ ] 测试 Jenkins 验收一个替代入口当前统一配置场景。
- [ ] 测试 Jenkins 验收一个仓库分发预检运行场景。
- [ ] 测试 Jenkins 验收一个交付预检拒绝且无交付副作用的场景。
- [ ] 验收覆盖 CPS 序列化、阶段创建、节点选择、凭据别名、环境变量、产物交接、终止和工作区清理。
- [ ] 验收不向生产环境执行部署。
- [ ] 接入说明明确新旧入口的适用对象、配置结构、兼容承诺和错误语义。
- [ ] 回退说明能将每个增量阶段恢复到前一可用实现，而不要求删除既有入口。
- [ ] 验收结果和已知限制被记录，规格中的所有 acceptance scope 均有证据。
