# 01 — 锁定既有入口兼容基线

**What to build:** 通过公开入口建立 `deployWeb`、`deployJavaWeb` 和 `dispatchCodeupRepositories` 的兼容样本集，锁定合法旧配置、配置优先级、失败语义与可观察结果，使后续迁移可以证明没有破坏既有入口契约。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 样本覆盖三个既有入口当前支持的调用方式和合法旧配置结构。
- [ ] 样本覆盖共享库默认配置、扩展配置、主交付配置和执行覆盖的既有优先级。
- [ ] 样本区分可选配置缺失与配置格式、读取或解析失败。
- [ ] 样本覆盖成功、失败、终止、通知失败和工作区清理失败的既有可观察语义。
- [ ] 仓库分发样本覆盖仓库授权、受限声明、命令授权、继续执行和末尾失败。
- [ ] 测试只从公开入口调用，不直接调用内部兼容或合并方法。
- [ ] 当前实现不发生行为变更，完整测试保持通过。
